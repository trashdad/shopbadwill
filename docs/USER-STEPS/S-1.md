# USER STEP S-1: logged-in captures and search-page DOM (about 30 minutes)

**Why you:** robots.txt forbids automated loads of search pages and account pages, and the worker never logs in as you. These captures fill the last S-1 fixtures and verdicts (`docs/spikes/S-1.md` §8).

**Nothing here bids, saves or changes your account.** Two steps open a dialog and close it again. Step 0.5 also makes DevTools block the four write endpoints these pages can reach (`ItemBid/PlaceBid`, `Favorite/Save`, `AddToFavorite`, `RemoveItemFromFavoriteList`), so a slip of the mouse is harmless.

**Never paste, into chat or into any file:**
- your password;
- request headers, cookies, or anything starting `eyJ` (your login token);
- "Copy as cURL", "Copy all as HAR" or "Save all as HAR";
- `redact.txt`.

You only copy **response bodies** and **page HTML**, exactly as below.

Raw files go to `test/fixtures/sgw/raw/user/`, which git ignores; the worker sanitizes them before anything is committed. Use Chrome on Windows.

## 0. Setup (once)

0.1. In PowerShell, run this. `Save-Clip` writes the clipboard to a file in that folder (UTF-8, no BOM).
```powershell
$R = 'C:\tools\shopbadwill-wt\T-07'
$U = "$R\test\fixtures\sgw\raw\user"
New-Item -ItemType Directory -Force $U | Out-Null
function Save-Clip($name) { [IO.File]::WriteAllText("$U\$name", (Get-Clipboard -Raw)); Get-Item "$U\$name" | Select-Object Name, Length }
```
0.2. Run `notepad "$U\redact.txt"`. Type, one per line, everything personal the site shows you:
- your ShopGoodwill username;
- your first name and your last name as the site shows them;
- your email;
- each saved address's street line (e.g. `12 Elm Way`), city, and ZIP;
- your phone number, written the way the site shows it.

Save the file and **do not paste it anywhere.** The sanitizer replaces these strings in every capture and refuses to build if one survives. It also drops, on its own:
- saved addresses in the item page's shipping tab;
- your state, country and the province field;
- tokens and ids.

The list above is the safety net for anything else.

0.3. **How to copy page HTML** (steps 1, 2, 4, 5, 6, 9):
1. Wait until the listings show prices.
2. Press F12, go to **Console**, and run `copy(document.documentElement.outerHTML)`. The first time, Chrome asks you to type `allow pasting`; do that, then run the line again.
3. In PowerShell, run `Save-Clip <name>`.

0.4. **How to copy a JSON response** (steps 6, 7, 8, 9, 11):
1. Keep DevTools open on the **Network** tab *before* the action, and type the endpoint name in the filter box.
2. Right-click the matching row and choose **Copy → Copy response**. Never choose the other Copy entries.
3. In PowerShell, run `Save-Clip <name>`.
4. Note the row's **Request URL** (Headers tab, first line) in `notes.txt` (step 12).

0.5. **Safety net (Part B tab, before step 4):**
1. Open DevTools and press Ctrl+Shift+P.
2. Type `blocking` and open **Network request blocking** (newer Chrome calls it **Request conditions**).
3. Tick **Enable**.
4. With **+**, add these four patterns: `*ItemBid/PlaceBid*`, `*Favorite/Save*`, `*AddToFavorite*`, `*RemoveItemFromFavoriteList*`.

Keep DevTools open in that tab for steps 4-11.

## Part A: logged out

1. Open an Incognito window (Ctrl+Shift+N) and go to `https://shopgoodwill.com/categories/listing?st=pyrex&layout=grid`. Copy the page HTML (0.3), then run `Save-Clip search-grid-logged-out.html`.
2. Go to the same URL with `&layout=list`. If you still see tiles, click the site's list-view toggle. Copy the page HTML, then run `Save-Clip search-list-logged-out.html`. Close the Incognito window.

## Part B: logged in (normal window)

3. Sign in as usual. In `notes.txt`, note whether the sign-in page showed an "I'm not a robot" box, a picture puzzle, or a small reCAPTCHA badge (bottom right).
4. Set up the safety net (0.5). Then open `https://shopgoodwill.com/categories/listing?st=pyrex&layout=grid`. Copy the page HTML, then run `Save-Clip search-grid-logged-in.html`.
5. Switch to the list layout (`&layout=list` or the toggle). Copy the page HTML, then run `Save-Clip search-list-logged-in.html`.
6. **Item page, logged in.** Both files are required: the sanitizer learns the seller (name, city, street, ZIP) from the JSON, and refuses to build the page without it.
   1. In the Network filter, type `GetItemDetailModelByItemId`.
   2. Open any **open** auction from the results.
   3. Copy the response of the `GetItemDetailModelByItemId` row (the **Response** tab only, never headers, cURL or HAR), then run `Save-Clip item-detail-logged-in.json`.
   4. Copy the page HTML, then run `Save-Clip item-page-logged-in.html`.
7. **Bid popup (read-only):**
   1. Go back to the results. In the Network filter, type `ShowBidModal`.
   2. On any card, click **Quick Bid**. A popup opens.
   3. **Do not click "Place Bid".** Click **Close**, or press Esc.
   4. Copy the response of the `ShowBidModal` row, then run `Save-Clip show-bid-modal.json`.
   5. Note in `notes.txt` whether the popup showed any reCAPTCHA.
8. **Shipping estimate:**
   1. Open the auction from step 6 and go to its **Shipping** tab.
   2. Country: United States. ZIP: `60601` (any ZIP works; you don't need your own).
   3. In the Network filter, type `CalculateShipping`, then click **Get Estimate**.
   4. Copy the response, then run `Save-Clip calculate-shipping.json`.
   5. In the same row's **Payload** tab, click **view source**, select all, copy, then run `Save-Clip calculate-shipping.request.json`.
   6. Note what the page displays (for example "Shipping $12.34, Handling $5.00").
9. **Favourites:** in the Network filter, type `GetAllFavoriteItemsByType`. Open `https://shopgoodwill.com/shopgoodwill/favorites`.
   - Copy the response of the row whose URL ends `Type=open`, then run `Save-Clip favorites-open.json`.
   - Copy the page HTML, then run `Save-Clip favorites-page.html`.
   - If you have no open favourites, skip this step and say so. Don't add one just for this.
10. **Note length (no save):**
    1. On the favourites page, click **Add note** (or **Edit note**) on one item.
    2. Right-click the note box, choose **Inspect**, and note its `maxlength="…"` value, or "none".
    3. In the Console, run `copy('x'.repeat(600))` and paste into the note box.
    4. Note what the dialog does: a counter, an error text, or cutting the text off, and at how many characters.
    5. Click **Cancel** or **Close**, never **Save**. The note text you had before stays unchanged.
11. **Saved searches (optional):** the names and queries of your saved searches **are committed** after sanitizing, because they are the fixture. Skip this step if you'd rather not share them, and say so; T-26 then builds on the community shape.
    1. In the Network filter, type `GetSaveSearches`.
    2. Open `https://shopgoodwill.com/shopgoodwill/saved-searches`.
    3. Copy the response, then run `Save-Clip saved-searches.json`.

    If you have no saved searches, say so.
12. Run `notepad "$U\notes.txt"` and fill in:
    ```
    signin-recaptcha:      yes/no (what you saw)
    bidpopup-recaptcha:    yes/no
    item-detail URL:       https://buyerapi.shopgoodwill.com/api/ItemDetail/GetItemDetailModelByItemId/...
    show-bid-modal URL:    https://buyerapi.shopgoodwill.com/api/ItemBid/ShowBidModal?itemId=...
    calculate-shipping:    URL ... ; page showed shipping $... handling $...
    favorites URL:         ...
    saved-searches URL:    ...
    note maxlength:        ... (or none)
    note 600-char test:    what the dialog did
    skipped:               any step you skipped, and why
    ```
13. **Clean up:** in the blocking panel (0.5), untick **Enable** and delete the four patterns, so they never block a real bid later.
14. Check the files: run `Get-ChildItem $U | Select-Object Name, Length`. Expect up to 14 files: 6 `.html`, 6 `.json` (counting `calculate-shipping.request.json`), `redact.txt` and `notes.txt`.
